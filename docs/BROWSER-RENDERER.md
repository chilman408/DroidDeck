# Choose an H.264 renderer

Open **Settings → Display → Renderer**. Choose **H264 (WebCodecs)** to use the browser's native decoder. Choose **H264 (Legacy)** if WebCodecs gives you a black screen or plays poorly.

Both modes play the same video stream. This setting changes how the browser decodes video. **Video Encoding** is a separate setting that controls whether the Ubuntu machine uses the GPU or CPU to compress the stream.

To check what is running, read the Display and Audio rows below **Updates** in the main Settings menu. Test a Tesla browser while parked.
