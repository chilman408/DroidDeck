# DroidMate 0.1.2

- See live Display, Audio and GPS status directly below **Updates** in Settings.
  The summary shows the current stream settings and automatic quality limits.
- Audio status changes to **Playing** when browser audio starts.
- In-place upgrades from 0.1.1 retain Android apps, data and lockscreen settings.
  If the old GPU worker exits while an upgrade is draining it, the installer
  can finish the recorded recovery before continuing.

The signed Android core remains `0.1.1-rc.20`. Follow the installation guide
for a fresh Ubuntu install or a preserving update.
